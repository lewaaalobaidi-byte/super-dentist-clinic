# Super Dentist Clinic – Erbil

Website for Super Dentist Clinic (Arabic / English / Kurdish), hosted on GitHub Pages.

- Pages are generated by `_source/build.py` from `_source/content.py`.
- CSS is pre-built Tailwind (`styles.css`). Rebuild after adding new classes:
  `npx tailwindcss@3 -c _source/tailwind.config.js -i _source/input.css -o styles.css --minify`
- Photos: `gallery/` (before/after, patient consent required), `tour/` (clinic photos).
